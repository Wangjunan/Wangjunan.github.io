1. 如何把高颜值设计稿真正落地到“传明酸美白面膜内袋”？

方案 A · 磨砂纯铝临床极简（稳重高级）

借鉴 D169 / D170 / VERSO：哑光纯铝银底或冷灰白底，大幅留白，仅保留大字距无衬线英文 TRANEXAMIC ACID + 1 处冷钴蓝/宝石红点睛小标。

方案 B · 珠光虹彩渐变提亮（强美白联想）

借鉴 D002 / D216 / D205：浅珍珠白向冰蓝或淡丁香紫斜向渐变，可叠加局部微全息镭射条带，配细密标尺刻度强化有效成分心智。

方案 C · 东方留白莫兰迪植萃（温柔有温度）

借鉴 D163 / D178 / D179：哑光暖奶白底 + 低饱和豆沙绿/裸杏几何圆窗或局部烫香槟金框块，适合主打“敏感肌也能用的温和传明酸”。

3. 法规标签底线（《化妆品标签管理办法》）

美白特证与成分表写法

  • 宣称“美白/祛斑”须取得国家药监局“国妆特字”批号，并禁绝“速效祛斑、根除黑色素”等绝对化用语。
  • 全成分表内传明酸标准中文名须标注为“氨甲环酸”。

内袋正背面最小信息与钢印区

  • 随外盒销售时，内袋上至少须清晰标注产品中文名称和使用期限；独立单片零售则须具备完整标签。
  • 热封边处须预留 ≥12mm 无图案浅色区，确保批号及限期使用日期钢印清晰可读。
